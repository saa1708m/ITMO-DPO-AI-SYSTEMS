# M6 code examples

Каталог `attachments` содержит демонстрационные примеры для модуля 6 «Развёртывание и масштабирование моделей».

## Состав

- `lab_6_1_rest_api_model.ipynb` — Jupyter-ноутбук с примером реализации REST API для serving модели;
- `lab_6_2_kubernetes_canary.ipynb` — Jupyter-ноутбук с примером canary-развёртывания модели в Kubernetes.

## Назначение

Примеры предназначены для самостоятельного изучения и воспроизведения на учебных данных dry beans (модуль 3). Ноутбуки могут использоваться как основа для выполнения лабораторных работ модуля 6.
