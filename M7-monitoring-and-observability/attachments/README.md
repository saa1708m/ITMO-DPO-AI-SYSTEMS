# M7 code examples

Каталог `attachments` содержит демонстрационные примеры для модуля 7 «Мониторинг и наблюдаемость ML-систем».

## Состав

- `prometheus_dry_beans.yml` — пример конфигурации Prometheus для сбора метрик с сервиса dry beans;
- `grafana_dry_beans_dashboard.json` — пример дашборда Grafana для визуализации метрик сервиса.

## Связанные компоненты

- docker-compose окружение модуля 4: `../../M4-containerization/attachments/docker-compose.yml`;
- учебный датасет для анализа дрейфа: `../../resources/datasets/module_07/`.
