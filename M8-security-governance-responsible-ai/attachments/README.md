# M8 code examples

Каталог `attachments` содержит демонстрационные примеры для модуля 8 «Безопасность, governance и Responsible AI».

## Состав

- `lab_8_1_secrets_rbac.ipynb` — Jupyter-ноутбук с примерами управления секретами, RBAC и безопасной конфигурацией ML-сервиса;
- `lab_8_2_bias_audit.ipynb` — Jupyter-ноутбук с примером аудита смещений (bias audit) и оценки справедливости модели.

## Назначение

Примеры предназначены для самостоятельного изучения и воспроизведения на учебных данных (dry beans, модуль 3; данные для анализа дрейфа, модуль 7). Ноутбуки могут использоваться как основа для выполнения лабораторных работ модуля 8.
