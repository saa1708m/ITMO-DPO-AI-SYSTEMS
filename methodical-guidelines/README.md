# Методические указания

Раздел содержит материалы для студентов и преподавателей, связанные с выполнением заданий, оцениванием, использованием ресурсов и организацией контроля.

- `students/` — рекомендации обучающимся;
- `teachers-assessment/` — рекомендации преподавателям по оцениванию;
- `teachers-assessment/guide.md` — [руководство преподавателя по развёртыванию окружения](teachers-assessment/guide.md);
- `teachers-resources/` — рекомендации преподавателям по использованию ресурсов.

Отдельные разделы методических указаний описывают правила использования генеративного ИИ (LLM) и внешних ресурсов для обучающихся и преподавателей. Рекомендуется предварительно ознакомиться с этими правилами перед выполнением и проверкой заданий.
