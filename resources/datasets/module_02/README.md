# Модуль 2. Управление данными и их версионирование

## Учебное применение

В лабораторной 2.1 можно построить профиль пропусков, сравнить станции и сезоны, исследовать связь PM2.5 с погодой, проверить выбросы и выбрать стратегию заполнения значений. В лабораторной 2.2 тот же файл подходит для DVC, ETL и автоматических проверок: уникальность пары `timestamp`–`station`, полный часовой календарь, допустимые диапазоны концентраций, согласованность календарных признаков и доля пропусков.

Практическое задание: подготовить очищенную витрину для прогноза `pm2_5_ug_m3`, выполнить временное разбиение без утечки из будущего и оформить проверки качества входных данных.

## Столбцы


| Столбцы                                          | Содержание                                      |
| ------------------------------------------------ | ----------------------------------------------- |
| `timestamp`, `station`                           | Час наблюдения в ISO 8601 и код станции         |
| `year`, `month`, `day`, `hour`                   | Календарные признаки, извлечённые из даты       |
| `pm2_5_ug_m3`, `pm10_ug_m3`                      | Концентрации частиц PM2.5 и PM10, мкг/м³        |
| `so2_ug_m3`, `no2_ug_m3`, `co_ug_m3`, `o3_ug_m3` | Концентрации газообразных загрязнителей, мкг/м³ |
| `temperature_c`, `pressure_hpa`, `dew_point_c`   | Температура, давление и точка росы              |
| `rain_mm`                                        | Осадки, мм                                      |
| `wind_direction`, `wind_speed_m_s`               | Направление и скорость ветра                    |
| `missing_measurements`                           | Число отсутствующих показателей в строке        |


## Выполненные преобразования

Из 12 станций выбраны Aotizhongxin и Dingling, а временной диапазон ограничен полным високосным 2016 годом. Это детерминированный фильтр, а не случайная выборка; random seed не требуется. Технический номер строки `No` удалён, дата собрана из четырёх исходных полей и приведена к ISO 8601, имена столбцов приведены к `snake_case`, код станции — к нижнему регистру. `NA` преобразованы в пустые CSV-поля, добавлен счётчик пропусков. В итоговой таблице 1 518 строк хотя бы с одним пропуском и 2 850 пустых ячеек; полных дубликатов нет.

Синтетические строки и значения не добавлялись. Естественные пропуски не заполнялись, чтобы не подменять задачу очистки готовым решением.

## Воспроизведение

Из корня репозитория:

```bash
python3 resources/datasets/module_02/prepare_dataset.py
```

Сценарий использует только стандартную библиотеку Python. При автоматической загрузке архив сохраняется во временный каталог и удаляется после подготовки CSV.
