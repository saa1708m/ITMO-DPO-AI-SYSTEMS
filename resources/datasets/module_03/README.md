# Модуль 3. Разработка, эксперименты и версионирование моделей

## Датасет

Исходные признаки получены системой компьютерного зрения из фотографий отдельных зёрен. Это компактная многоклассовая задача без персональных и текстовых данных: удобно сравнивать линейную модель, дерево и ансамбль, выбирать macro-F1 и balanced accuracy, анализировать confusion matrix и логировать эксперименты в MLflow.

## Учебное применение

В лабораторной 3.1 предлагается построить минимум три бейзлайна в едином `Pipeline`, выполнить стратифицированное разбиение, сравнить качество и время обучения, сохранить метрики и confusion matrix в MLflow. В лабораторной 3.2 лучшую модель можно зарегистрировать, оформить model card и проверить инференс из Model Registry.

Практическое задание: определить сорт по морфологическим измерениям, отдельно разобрать пары классов, которые модель путает чаще всего, и обосновать критерий продвижения модели в `Production`.

## Столбцы


| Столбцы                                                | Содержание                                                                          |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------- |
| `area_pixels`, `perimeter_pixels`                      | Площадь и периметр сегмента зерна                                                   |
| `major_axis_length_pixels`, `minor_axis_length_pixels` | Длины большой и малой осей                                                          |
| `aspect_ratio`, `eccentricity`                         | Вытянутость формы                                                                   |
| `convex_area_pixels`, `equivalent_diameter_pixels`     | Площадь выпуклой оболочки и эквивалентный диаметр                                   |
| `extent`, `solidity`, `roundness`, `compactness`       | Безразмерные характеристики формы                                                   |
| `shape_factor_1` … `shape_factor_4`                    | Дополнительные коэффициенты формы из исходного набора                               |
| `convexity_gap_pixels`                                 | Разность площади выпуклой оболочки и площади зерна                                  |
| `normalized_perimeter`                                 | Периметр, делённый на квадратный корень площади                                     |
| `bean_variety`                                         | Целевой сорт: `barbunya`, `bombay`, `cali`, `dermason`, `horoz`, `seker` или `sira` |


## Выполненные преобразования

ARFF преобразован в UTF-8 CSV; названия полей исправлены и приведены к `snake_case`; числовая точность ограничена шестью знаками после запятой. Удалены 68 полных дубликатов. Добавлены два интерпретируемых признака формы — зазор выпуклой оболочки и нормированный периметр; классы приведены к нижнему регистру. Порядок объектов после удаления дубликатов сохранён.

Синтетические строки и значения не добавлялись. Случайная выборка не формировалась: полный очищенный набор укладывается в ограничения по объёму.
