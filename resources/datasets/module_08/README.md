# Модуль 8. Безопасность, governance и ответственный ИИ

## Датасет

Adult построен на обезличенной выборке из переписи населения США 1994 года и не содержит имён, адресов или идентификаторов. При этом `sex` и `race` являются чувствительными атрибутами. Они сохранены только потому, что лабораторная 8.2 прямо требует измерять качество и fairness по группам. Набор исторический, отражает социальные неравенства своего времени и не должен применяться для решений о конкретных людях.

## Учебное применение

Данные подходят для полного цикла лабораторной 8.2: baseline-классификация, `MetricFrame`, demographic parity difference, equalized odds difference, сравнение recall по группам и mitigation. Столбец `source_split` позволяет сохранить исходное разделение UCI и обсудить риск подгонки по тестовой части.

Практическое задание: обучить модель без `sex` и `race` во входных признаках, проверить, сохраняется ли групповое смещение через proxy-признаки, применить один метод mitigation и оформить ограничения в Model Card.

## Выполненные преобразования

Объединены файлы `adult.data` и `adult.test`; у тестовых меток удалена завершающая точка; пробельные отступы категорий очищены; `?` заменён пустым CSV-полем. Технический вес переписи `fnlwgt` исключён. После этого удалены 4 487 полных дубликатов по всем оставшимся полям. Поля переименованы, цель закодирована как 0/1, добавлена возрастная группа и сохранена исходная принадлежность к train/test.

Из очищенных записей отобрано 15 000 с `random seed = 42`. Стратификация одновременно учитывает `high_income`, `sex` и `source_split`, поэтому сохранены близкие к очищенному источнику пропорции цели и групп: 11 325 записей класса 0 и 3 675 класса 1; 9 840 строк из train и 5 160 из test. В итоговой таблице 2 071 пустое значение, происходящее только из исходных `?`.

Синтетические строки и значения не добавлялись.
